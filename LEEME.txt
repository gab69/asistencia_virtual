MARCADOR DE ASISTENCIA  -  Desarrollado por @GabRC
======================

A) PARA CREAR EL INSTALADOR (una sola vez, en UN equipo Windows con Python)
   1. Instala Python desde https://www.python.org (marca "Add Python to PATH").
   2. Doble clic en  construir_instalador.bat
      (instala lo necesario, incluido Inno Setup, y arma todo solo).
   3. Al terminar se abre la carpeta Output con:
        Instalador_MarcadorAsistencia.exe
   4. Copia ese unico archivo a los demas equipos.

B) PARA INSTALAR EN CADA EQUIPO (no requiere Python ni administrador)
   1. Doble clic en Instalador_MarcadorAsistencia.exe
   2. Siguiente > Siguiente > Instalar.
      Deja marcada la opcion "Iniciar con Windows".
   3. Se abre el programa: configura pagina, horarios y dias, y pulsa Guardar.

DESINSTALAR
   - Desde el programa: boton rojo "Desinstalar".
   - O desde Configuracion de Windows > Aplicaciones > Marcador de asistencia.
   Se cierra el programa, se quita el inicio con Windows y se borran el
   programa y la configuracion (%USERPROFILE%\marcador_asistencia.json).

USO DIARIO
   - Alarma sonora: se activa o desactiva en "Seguridad y alarma" (boton "Probar"
     para revisar el volumen). Suena hasta que marques o liberes el bloqueo.
   - La pagina de asistencia se muestra maximizada (pantalla completa).
   - El boton "Emergencia" abre una ventana centrada, siempre al frente.
   - Al cerrar la ventana con la X, el programa sigue activo junto al reloj
     (icono azul con check; si no lo ves, pulsa la flecha ^).
   - Clic en el icono = abrir configuracion. Clic derecho = Abrir / Salir.
   - Si la pagina pide usuario y contrasena, deja activado
     "Permitir todo el navegador".
   - Si te bloqueas: boton "Emergencia" (tu codigo) o espera el limite de minutos.

MODO DESARROLLO (opcional): iniciar.bat ejecuta el programa desde el codigo
fuente y desinstalar.bat lo quita.
